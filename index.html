Высокопроизводительный асинхронный протокол Minecraft Bedrock

Мощный двигатель на Python для запуска одиночных ботов, масштабных мульти-бот роев (Swarm), собственного Bedrock-сервера и анализатора трафика (Relay).

Примеры кода Мульти-Бот Кластеры 

        

      

    

  


  
  

    

      
Почему именно r-python-bedrock-protocol?

      
Максимальная производительность, гибкость конфигурации и готовность к сложным нагрузкам.


      

        

          
⚡

          
AsyncIO & RakNet Transport

          
Построено на событийно-ориентированной архитектуре `asyncio` с поддержкой `uvloop` для минимальных задержек и высокой пропускной способности пакетов.

        


        

          
🤖

          
Мульти-Боты (BotCluster)

          
Встроенная система управления десятками параллельных ботов: авто-переподключение, общая рассылка сообщений, единая статистика и изоляция состояний.

        


        

          
🔒

          
Native Cryptography

          
Прямая интеграция OpenSSL (`cryptography`) для генерации ECDH-ключей и шифрования сетевых пакетов по стандарту AES-256-CFB8.

        


        

          
📱

          
Спуфинг Устройств

          
Полный контроль над идентификацией клиента: эмуляция Windows, Android, iOS, Nintendo Switch, установка любого DeviceID, Model и ClientRandomID.

        


        

          
📊

          
Автоматический Лог и Статистика

          
Встроенный сбор истории чата в JSON, отдельное логирование сообщений, подсчет пакетов, времени аптайма и ошибок в реальном времени.

        


        

          
🛠️

          
Relay MITM & Server

          
Входит полноценный протокольный сервер `create_server` и прокси-инструмент `Relay` для перехвата, модификации и отладки пакетов Bedrock.

        

      

    

  


  
  

    

      

        

          Сложные Проекты и Оркестрация
          
Управление Параллельными Ботами и Сложная Автоматизация

          

            Благодаря встроенному `BotCluster` вы можете запускать бот-сети для стресс-тестов, мостов с Discord/Telegram, авто-модераторов, мониторинга онлайна и сбора аналитики.
          

        


        

          

            
🔥 Стресс-тестирование Серверов

            
Создание роя из 10-50 ботов с разной конфигурацией устройств для проверки устойчивости спавна и RakNet-соединений.

          


          

            
💬 Мост Игрового Чата

            
Пересылка игрового чата в Telegram/Discord и отправка ответов обратно в Minecraft через асинхронные события `@bot.on("chat")`.

          


          

            
📈 Сборщик Метрик и Логер

            
Непрерывный мониторинг онлайна игрового сервера, сохранение логов чата в JSON и отслеживание задержек.

          

        

      

    

  


  
  

    

      
Справка по API Библиотеки

      
Ключевые классы и функции для разработки.


      

        

          
            

              Класс / Функция
              Назначение
              Основные методы и параметры
            

          
          
            

              Bot(host, port, config)
              Высокоуровневый бот Minecraft Bedrock с авто-реконнектом.
              start(), run(), stop(), send_message(), send_command(), stats
            

            

              BotCluster
              Оркестратор для группы ботов.
              create_swarm(), add_bot(), run_all(), stop_all(), broadcast()
            

            

              BotConfig
              Гибкая конфигурация сессии.
              username, device, version, auto_reconnect, reconnect_delay, chat_autosave_file
            

            

              ping(host, port)
              Получение статуса сервера без авторизации.
              Возвращает ServerAdvertisement (motd, online, max_players, protocol, version)
            

            

              create_server(host, port)
              Запуск собственного Bedrock сервера.
              listen(), обработка подключения клиентов @server.on('connect')
            

            

              Relay(host, port)
              MITM-прокси для анализа и подмены пакетов.
              Перехват входящих и исходящих пакетов в реальном времени
